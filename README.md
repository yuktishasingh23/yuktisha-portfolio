## 👩‍💻 About the Project

This is my personal portfolio website, built to present my technical skills, academic journey and development projects in a professional and interactive way.

## 🚀 Features

- Responsive design for desktop, tablet and mobile.
- Dark theme with lavender accents.
- Animated typing text.
- Interactive project cards with 3D hover effects.
- Scroll reveal animations.
- Animated buttons and ripple effects.
- Skills, education and project sections.
- Certifications and workshop details.
- Resume download and contact links.
- Back-to-top button.

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, responsive design and animations
- JavaScript — Interactive functionality
